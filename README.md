# Quantum Monte Carlo QMC Agent

An educational one-dimensional **variational Monte Carlo (VMC)** sampler alongside two legacy rule-based task-audit interfaces. The physical sampler estimates the energy of a quantum harmonic oscillator using seeded random-walk Metropolis sampling. It runs in modern browsers without a server and is also available from Python.

## What works

- **Browser VMC demonstration**: adjust trial parameter α, proposal width, sample count, burn-in, and seed; inspect sample-block energy estimates and download JSON.
- **Python VMC**: reproducible seeded samples, acceptance rate, variational energy, and batch-mean standard error.
- **Legacy audit API and CLI**: three simple threshold/descriptor checks, bulk CSV audits, query responses generated by a deterministic mock, and in-memory HMAC-chained audit records.
- **Separate legacy `qmc_simulator` auditing API**: available through `qmc_simulator.server` for compatibility.

**Scope:** The sampler models a single 1D harmonic oscillator. It is **not** diffusion Monte Carlo, fixed-node DMC, quantum hardware, a validated financial option-pricing tool, or a clinical decision system. The older “agents” are threshold checks, not QMC algorithms or learned physics models. The enrichment suite contains threshold-based placeholders, not option-pricing calculations.

## Browser use

Open `web/index.html` through a local web server:

```sh
python -m http.server 8080 --directory web
```

Open `http://localhost:8080` in a browser, enter simulation parameters, and select **Run simulation**. Module imports require an HTTP server rather than a direct `file://` URL. The browser demonstration has no external computational dependencies; numerical inputs remain local to the device. Exported JSON includes the settings, statistics, and sample-block averages.

## Python setup

Python **3.10+**:

```sh
python -m pip install -e ".[server,test]"
python -m pytest -q
python -m qmc_simulator.cli vmc --alpha 0.85 --samples 10000 --burn-in 1000 --proposal 1.5 --seed 42
```

The packaged `quantum-monte-carlo-qmc-engine vmc` entry point is equivalent to the last command. The separate `quantum-monte-carlo-audit` command runs the legacy rule-based audit.

## Mathematical formulation

In units where ℏ = m = ω = 1:

- Hamiltonian: `H = −½ d²/dx² + x²/2`
- Gaussian trial state: `ψα(x) = exp(−αx²/2)`
- Metropolis target distribution: `|ψα(x)|²`
- Local energy: `E_L(x) = α/2 + (1−α²)x²/2`
- Analytic trial energy: `E(α) = (α + 1/α)/4 ≥ 0.5`

The estimated energy is a correlated Monte Carlo average. Error estimates use contiguous batch means; interpret them cautiously if the chain mixes poorly. With α = 1 the local energy is identically 0.5, providing a zero-variance reference test.

## Legacy audit usage

```sh
python cli.py audit --task-id CASE-01 --target SAMPLE-01 --primary 28.5 --secondary 14.2
python cli.py batch -i sample.csv -o results.csv
python cli.py verify-audit
python cli.py serve --host 127.0.0.1 --port 8000
```

The server exposes `GET /health`, `POST /api/audit`, `POST /api/chat`, and `GET /api/audit/logs`. API schemas can be explored at `/docs`. The separate `python -m qmc_simulator.cli serve` launches the compatibility server.

## Security and privacy

The browser sampler transmits no simulation inputs to a server. Python legacy audit data is processed in memory and is **not** persisted across restarts. The PHI guard uses heuristic regular expressions only; it is not guaranteed to identify or de-identify all sensitive information. **Do not use real patient data.** The HMAC log detects changes to in-memory signed entries but does not protect against host compromise or loss of the signing key. Server endpoints do not implement authentication and should not be exposed to untrusted networks without an authenticated reverse proxy and transport security.

Set a long, randomly generated `AUDIT_SECRET_KEY` in the environment for persistent signing key identity. Docker Compose requires this variable and does not embed a production secret:

```sh
export AUDIT_SECRET_KEY="$(python -c 'import secrets; print(secrets.token_hex(32))')"
docker compose up --build
```
